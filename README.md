# auction-house-lotTrio
AuctionHouse — backend-платформа онлайн-аукциона на Go, построенная на основе Layered Architecture. Включает JWT-аутентификацию, ролевую модель доступа, управление лотами, систему ставок, автоматическое закрытие аукционов, PostgreSQL, Docker и REST API.
